= Quality Requirements

== Quality Tree
The following tree prioritizes the most important quality attributes for PantryPal.

1. **Portability** (High)
   * Ability to run on Android and Desktop with >80% shared code.
2. **Availability** (High)
   * Core functionality (inventory viewing/editing) must be available 100% of the time offline.
3. **Usability** (Medium)
   * Efficiency of data entry through OCR and barcode scanning (future).
   * Low barrier to entry for non-technical users.
4. **Data Consistency** (Medium)
   * Eventual consistency between client and server.
   * Transparent conflict resolution.

== Quality Scenarios
[cols="1,2,1"]
|===
| Scenario | Description | Priority
| **Offline Usage** | A user adds a food item in a basement (no signal). The item is saved locally and synced automatically once signal is restored. | High
| **Platform Parity** | A feature added to the domain layer is immediately available for both Android and Desktop UI implementations. | High
| **Sync Conflict** | Two devices edit the same item while offline. Upon syncing, the version with the later "lastModifiedAt" timestamp is kept. | Medium
| **OCR Accuracy** | The system correctly identifies at least 90% of product names and expiration dates from clear photos of German/English labels. | Medium
|===
